# Question 3 - Screenshot Submissions Guidance

Save your Java Servlets, JSP & JDBC assignment screenshots in this directory:

### Recommended Screenshots:
1. `01_login_page.png`: The admin login page (`/login.jsp`) showing credentials form and demo login information.
2. `02_login_error_or_unauthorized.png`: Error alert on invalid password or unauthorized access redirect (`/login.jsp?error=unauthorized`).
3. `03_students_dashboard.png`: Authenticated student profile portal (`/students`) showing session user details, statistics counters, and multiple dynamically rendered student profile cards.
4. `04_streamed_profile_image.png`: Student profile photo dynamically streamed through `FileStreamServlet` (`/stream-file?name=...`).
5. `05_streamed_document_download.png`: Document stream and download dialog triggered via `FileStreamServlet` (`/stream-file?name=...&download=true`).
6. `06_logout_screen.png`: Secure logout screen acknowledging session invalidation (`/login.jsp?logout=true`).
7. `07_maven_build_success.png`: Terminal output showing `mvn clean package` BUILD SUCCESS and generated `target/student-portal.war`.
