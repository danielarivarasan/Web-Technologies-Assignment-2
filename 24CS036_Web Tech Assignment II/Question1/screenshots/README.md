# Question 1 - Screenshot Submissions Guidance

Save your assignment evaluation screenshots in this directory:

### Recommended Screenshots:
1. `01_initial_form.png`: The initial, clean state of the student registration form on desktop view.
2. `02_validation_errors.png`: The form displaying inline error messages (red borders, exclamation marks, and explanatory text) when submitting empty or invalid data.
3. `03_password_strength_and_match.png`: Real-time password strength meter (Fair/Strong) and confirm password matching validation.
4. `04_file_upload_preview.png`: Drag-and-drop file upload with selected filename and size badge.
5. `05_success_modal.png`: The registration summary modal after all client-side validation rules pass.
6. `06_responsive_mobile.png`: Mobile/tablet layout screenshot demonstrating responsive responsiveness.
