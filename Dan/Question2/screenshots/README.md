# Question 2 - Screenshot Submissions Guidance

Save your PHP & MySQL assignment screenshots in this directory:

### Recommended Screenshots:
1. `01_student_dashboard.png`: Student dashboard table view showing existing records, avatar thumbnails, and download links.
2. `02_add_student_form.png`: Adding a new student with profile photo and document file selection.
3. `03_validation_or_duplicate_error.png`: Validation error handling (e.g. duplicate roll number or file size/type rejection).
4. `04_student_profile_view.png`: Detail view (`view_student.php`) showing student details, rendered avatar, and stored file metadata.
5. `05_edit_student.png`: Editing student information and optionally replacing attached files.
6. `06_delete_confirmation_flash.png`: Deletion confirmation alert and flash message showing success.
7. `07_mysql_phpmyadmin.png`: phpMyAdmin or MySQL terminal showing records with file metadata inside table `students`.
